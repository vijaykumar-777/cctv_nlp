Install dependencies for the cctv_intelligence project.
Run from the project root with the venv active.


Step 1 — create and activate venv:
python3.11 -m venv .venv && source .venv/bin/activate


Step 2 — install torch first (CPU build, avoids 2GB CUDA download):
pip install torch==2.3.1 torchvision==0.18.1 --index-url https://download.pytorch.org/whl/cpu


Step 3 — install CV stack:
pip install numpy==1.26.4 Pillow==10.3.0 opencv-python-headless==4.9.0.80 ultralytics==8.2.100 boxmot==11.0.9 open_clip_torch==2.26.1


Step 4 — install API stack:
pip install fastapi==0.111.0 "uvicorn[standard]==0.30.1" sqlalchemy==2.0.30 asyncpg==0.29.0 alembic==1.13.1 "qdrant-client==1.9.1" redis==5.0.4 pydantic==2.7.1 pydantic-settings==2.3.0 aiosqlite==0.20.0


Step 5 — install NLP stack:
pip install anthropic==0.28.0 sentence-transformers==3.0.1 transformers==4.41.2 tokenizers==0.19.1


Step 6 — install utilities:
pip install ffmpeg-python==0.2.0 structlog==24.1.0 python-dotenv==1.0.1 httpx==0.27.0 pytest==8.2.2 pytest-asyncio==0.23.7


After each step, if there are version conflicts, resolve by:
  1. Do NOT change torch, numpy, ultralytics, or boxmot versions.
  2. For any other conflicting package, accept pip's suggested compatible version.


Verify install with:
python -c "import torch, cv2, ultralytics, boxmot, fastapi, qdrant_client, anthropic, open_clip; print('ALL OK')"


Report the output of that verify command.
